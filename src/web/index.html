CLI & API Usage

Command Line

npx shadowqa <sourceUrl> <targetUrl> [options]

Options

--viewport <preset|WxH>desktop (default), tablet, mobile, or custom WxH
--output <path>Output directory (default: ./reports)

Examples

# Desktop comparison (default)
npx shadowqa https://example.com https://example.com/de

# Mobile viewport
npx shadowqa https://example.com https://example.com/ja --viewport mobile

# Custom viewport
npx shadowqa https://example.com https://example.com/fr --viewport 1440x900

# Custom output directory
npx shadowqa https://example.com https://example.com/es --output ./my-reports

Development

# Run CLI directly with tsx (no build needed)
npm run cli -- https://example.com https://example.com/de

# Start web UI
npm run dev
